Le téléphone de l'éleveur

Un téléphone simple suffit, sans internet ni crédit : le menu passe par le réseau USSD de l'opérateur. Composez *123# puis Appeler. Le clavier de l'ordinateur fonctionne aussi : chiffres, lettres pour taper un code BG-…, Entrée, Retour et Échap.

Le réseau transmet ce numéro au serveur : c'est lui qui identifie l'éleveur.

Démonstration hors ligne : les menus tournent dans votre navigateur, avec des éleveurs et des vaches fictifs. Rien n'est envoyé. Rechargez la page pour repartir de zéro.
